# Support serviced Windows 11 x64 releases for v1

Version 1 of the packaged Operator Application will support only currently serviced Windows 11 x64 releases included in its tested release matrix. Windows 10 has left ordinary support, while Windows Server, ARM64, Wine, and compatibility layers would each expand the installer, native dependency, WebView2, capture, input, elevation, and failure-testing surface. The installer checks the packaged minimum OS build and architecture with a clear unsupported-platform explanation; lifecycle changes update future release matrices but do not remotely disable an installed offline application. Expanding the boundary requires platform-specific packaging and end-to-end live safety evidence rather than an assumption that Python unit tests imply desktop compatibility.

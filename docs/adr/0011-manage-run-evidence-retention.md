# Manage Run evidence retention

The packaged Operator Application will retain completed, unpinned Run evidence for 30 days and apply a 5 GB evidence budget by removing the oldest eligible Runs when necessary, replacing the source-tree dashboard's legacy 24-hour file cleanup. Active Runs and Pinned Runs are never deleted automatically; if protected evidence alone exceeds the budget, the application warns the operator instead of violating that protection. Run records, snapshots, timelines, logs, and artifacts form one Run Evidence Unit, while settings, recovery drafts, and editable Profile Packs remain outside this policy. Automatic retention permanently removes only eligible units; user-initiated deletion requires a completed, unpinned Run and moves its unit to the Windows Recycle Bin without any silent permanent-delete fallback. Operators can inspect usage, pin, export, unpin, and manually delete evidence so storage remains bounded without making important review material disappear unexpectedly.

# Elevate only the Live Run Worker

The Operator Application will normally remain unelevated and will launch a dedicated Live Run Worker at the target-required integrity level only after explicit live confirmation, instead of relaunching the entire interface as administrator or installing a permanent privileged service. The worker will receive a constrained run snapshot, communicate through a private authenticated channel, and release active input and fail closed if cancellation, ownership heartbeat, or application communication is lost. On later startup, a non-terminal Run owned by an earlier application session is verified safe, marked interrupted with its evidence preserved, and never resumed; inability to establish that the old worker can no longer send input blocks new Live Runs.

# Export versioned Evidence Bundles

Terminal Runs will export as standard ZIP Evidence Bundles with a self-contained HTML summary, versioned JSON manifest, Run Snapshot, readiness record, Timeline, log, artifacts, and SHA-256 checksums instead of a proprietary file or PDF-only report. Full Evidence preserves the complete Run Evidence Unit; an explicitly selected Shareable Bundle may omit operator-chosen categories, but its manifest and summary must identify every omission and must not claim complete evidence. The application will not attempt automatic image or free-text redaction because missed private content and altered evidence would create false confidence. This versioned, inspectable contract allows bundles to outlive the application while preserving both integrity and honest privacy boundaries.

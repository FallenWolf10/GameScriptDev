# Require verified, user-approved application updates

The packaged Operator Application will install an update only after showing its version and release notes, verifying both a trusted publisher signature and expected package hash, receiving explicit operator approval, and confirming that no Run is active. Update transactions replace only installed application and Built-in content, preserve the User Workspace and Operational Data, and retain a runnable prior version or equivalent rollback path if installation fails. Update checks are manual unless the operator explicitly enables no-more-than-weekly version-and-platform checks; checking can only notify, and updates are never installed silently or scheduled for later execution without renewed approval. Changed Built-in Packs produce Source Update comparisons for user-owned copies instead of modifying them. This keeps executable changes auditable without turning application maintenance into a mutation path for Profiles or Run evidence.
